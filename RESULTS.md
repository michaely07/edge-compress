# Experiment log

Chronological log of every measured number. `train.py`, `quantize.py`, `prune.py`, `calib.py`,
`bench.py` and `drone_data.py` each append a timestamped line as soon as a run produces a number.
Observations and notes are added by hand between entries.

This file is a lab notebook, not the source of the README. The README tables and figures are
generated from `results/<dataset>/*.json` by `report.py`, and each JSON also records the hardware and
library versions of its run.
